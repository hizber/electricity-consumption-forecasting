06 / FEATURE DECISIONS

What should the group test?

Ranked hypotheses for a shared, chronological validation protocol.

01 · START

Past consumption

Compare recent histories and daily or weekly lags on the same forecast hours. Include a previous-day baseline.

02 · ADD

Local calendar

Test hour, weekday, weekend, season and holiday features as one group against consumption alone.

03 · INVESTIGATE

Past temperature

Test temperature and rolling summaries only with a documented availability assumption. Keep weather results conditional until publication timing is verified.

Fit preprocessing and select features within training folds. Freeze choices before the assignment’s test and evaluation periods. Compare MAE and RMSE on identical target hours. Correlated variables can substitute for one another.
